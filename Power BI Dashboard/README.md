# 📊 Power BI Portfolio: Loan Default Prediction

## 📑 Executive Summary

This presentation provides an overview of my *Loan Default Prediction* initiative, designed to help financial institutions:

* Understand borrower behaviour
* Identify high-risk segments
* Make proactive, data-driven lending decisions

Using historical loan data, I transformed raw records into interactive *Power BI dashboards* that reveal clear patterns across *demographics, **behaviour, **financial attributes, and **institutional performance*.

---

### 🔍 At a Glance

* 🎯 *Objective* → Predict & monitor defaults
* 📊 *Approach* → Data + Dashboards + Modeling
* 🔑 *Insights* → Risk segmentation & borrower behaviour
* 💡 *Impact* → Smarter lending, reduced losses

---

### 📂 Storyline (Navigation)

* *Overview* → Big picture view
* *Behaviour* → How loans are used & repaid, why and where defaults occur (customer behaviour)

## 🖥️ Overview

![Overview Dashboard](./screenshots/overview.png)

Key highlights from the overview dashboard include:

* Loan default vs non-default distribution
* Default rates across borrower categories
* Snapshot of overall portfolio health

This consists of:

### 👤 Demographics Insights

* Age, employment status, and other borrower traits affecting default

### 📈 Behavioural Insights

* Payment delays, overdue first payment, time since last loan

### 💰 Financial & Loan Insights

* Debt-to-income ratio, loan-to-income ratio, outstanding balance

### 🌍 Geographical & Institutional Insights

* Default patterns by region, city, and bank
